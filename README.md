# Cucumelon Pixel Gallery

Build a modern, premium one-page NFT collection landing page for **CUCUMELON**.



## PROJECT



Name: **Cucumelon**



NFT collection:

**https://opensea.io/collection/cucumelon**



Cucumelon is a pixel-art NFT collection built around quirky, expressive cucumber/melon-inspired characters. The website is primarily a **brand landing page** and should direct visitors to the OpenSea collection.



Do NOT build a marketplace, minting system, wallet connection, or authentication system.



---



## DESIGN DIRECTION



Create a distinctive **pixel-art / retro Web3 aesthetic**.



Primary background:

**Light Lime — #E6FF66**



Supporting colors:



* Black — #0A0A0A

* Dark Green — #0D1B0D

* Lime — #99FF33

* Emerald — #00C853

* White — #FFFFFF



Visual style:



* Pixel-art inspired

* Retro arcade

* Modern Web3 branding

* Bold typography

* High contrast

* Slightly playful and weird

* Premium but not corporate

* Clean layout with lots of breathing room



Use subtle pixel patterns, small decorative squares, scanline effects and floating pixel elements.



Avoid excessive gradients.

# ANIMATIONS



Use subtle animations only.



Hero:



* Fade-in

* Slight upward movement



NFT cards:



* Hover scale 1.03

* Slight shadow movement



Buttons:



* Pixel-style hover effect

* Slight translateY



Background:



* Slowly floating pixel squares



Do NOT make animations heavy or slow.



The website must feel fast.



---



# RESPONSIVENESS



The website must be fully responsive.



Desktop:



* Large hero

* 3-column NFT grid

* Horizontal navigation



Tablet:



* 2-column NFT grid



Mobile:



* 1-column NFT grid

* Compact hero

* Hamburger navigation

* CTA buttons full width



Make sure text never overflows on mobile.



---



# TYPOGRAPHY



Use a bold pixel-inspired display font for headings.



Use a clean modern sans-serif font for body text.



Headings should feel like an arcade game / pixel NFT brand.



Use uppercase headings where appropriate.
